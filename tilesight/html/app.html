How much of each kernel the L2 / on-chip-buffer / L1 simulation replays, tile access by tile access. By default the whole kernel (every wave, every K step) up to this many accesses per kernel; a kernel over it drops waves first and K steps last. A longer window is slower but more accurate: capacity evictions (does the working set fit the L2, or the buffer every shader core shares) and 2 MB DMA-page reuse (the first K step into a page pays for all of it) only show up over a long enough trace — a short one sees only the first, compulsory misses and extrapolates them. The results show, per kernel, how much of it was actually replayed.
